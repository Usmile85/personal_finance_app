## 📊 About the Project

The **Personal Finance Tracker App** helps you monitor daily, weekly, and monthly spending habits across custom budget categories. Built with 🐍 Python and 🌐 Streamlit, it provides real-time summaries, bar charts, budget alerts, and supports CSV/Excel export.

---

## 🎯 Features

✅ Add and view expenses by category & subcategory  
✅ Track daily, weekly, and monthly spending  
✅ Set budgets and receive overspending alerts  
✅ Export expenses to CSV & Excel  
✅ Beautiful and mobile-friendly UI  
✅ Data visualizations: bar charts by category  
✅ Securely stores data locally as `personal_finance_log.csv`

---

## 🧱 Expense Categories

- 🍲 **Food & Groceries**

- 🕌 **Charity / Zakat**
- 🛍 **Shopping**
- 🎉 **Entertainment**

- 💰 **Savings**

## 🚀 How to Run Locally

```bash
# 1. Clone the repo
git clone https://github.com/Usmile85/personal_finance_app.git
cd personal_finance_app

# 2. Create and activate a virtual environment
python -m venv venv
venv\Scripts\activate  # On Windows

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run the Streamlit app
streamlit run streamlit_app.py
